# Security policy

## Reporting a vulnerability

Do not disclose vulnerabilities, access tokens, customer data, payment evidence, or other sensitive material in a public issue. Use GitHub's private vulnerability reporting for this repository. If private reporting is unavailable, contact the repository owner privately through GitHub before sharing technical details.

Include the affected component, impact, reproducible steps that do not expose real user data, and any suggested mitigation. Reports are triaged in good faith; do not access or modify data that is not yours.

## Deployment responsibilities

This repository does not supply production credentials, provider approval, managed infrastructure, or an incident-response service. Operators must maintain supported dependencies, restrict and rotate secrets, protect backups, monitor deployments, and apply reviewed security updates.
