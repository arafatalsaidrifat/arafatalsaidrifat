# F-Commerce OS

A production-oriented multi-phase commerce operations platform for Bangladeshi social sellers.

The complete application source is maintained on the [`f-commerce-os` branch](https://github.com/arafatalsaidrifat/arafatalsaidrifat/tree/f-commerce-os).

The source includes a Next.js/TypeScript app, Prisma/PostgreSQL domain model, tenant-aware API foundations, webhook and outbox safeguards, integration adapters, automated tests, Docker Compose services, CI configuration, and setup/validation documentation.

> This is an in-development platform. Configure environment variables and complete the documented build, database, provider, and security verification before production use.
